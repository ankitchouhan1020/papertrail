# Community plugin checklist (Papertrail)

- [ ] `manifest.json` / `versions.json` / `README` / `LICENSE` in repo
- [ ] Source in **`src/main.ts`**; run **`npm run build`** before release so root **`main.js`** is current
- [ ] GitHub release includes **`main.js`**, **`manifest.json`**, **`styles.css`**
- [ ] See [Developer policies](https://docs.obsidian.md/Developer+policies) and [Submission requirements](https://docs.obsidian.md/Plugins/Releasing/Submission+requirements+for+plugins)
